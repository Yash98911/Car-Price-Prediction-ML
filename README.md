# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview
This project builds an end-to-end regression pipeline to predict car prices using structured data. The workflow includes data cleaning, feature engineering, preprocessing using ColumnTransformer, model comparison, and final model selection using Ridge Regression.

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 🧠 ML Workflow
- Data Cleaning & Preprocessing
- Outlier Handling
- Log Transformation
- Train-Test Split
- ColumnTransformer + Pipeline
- Model Comparison
- Cross Validation
- Final Ridge Regression Model

## 📊 Final Model Performance
- Test R² (log scale): ~0.65
- Cross-validation R²: ~0.64
- MAE (Real Price): ~₹2,00,000

## 🚀 Key Learning
- Implemented full ML pipeline
- Handled unseen categories in OneHotEncoder
- Applied log transformation and inverse transformation
- Compared multiple regression models
- Avoided data leakage using Pipeline
